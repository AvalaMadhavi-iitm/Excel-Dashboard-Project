# Digital Marketing Excel Dashboard

## Project Overview

This project analyzes digital marketing campaign data for ABC Ltd using Microsoft Excel.

The dashboard evaluates campaign performance across different companies, marketing channels, and years.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Analysis

## Key Metrics

- Conversion Rate
- ROI
- Clicks
- Engagement Score
- Year

## Dashboard

The dashboard contains:

- Average Conversion Rate by Year
- Total Clicks by Year
- Average ROI by Year
- Total Engagement by Year
- Channel slicer
- Company slicer

The slicers allow users to filter the dashboard by company and marketing channel.

## Key Findings

NexGen Systems showed strong overall digital marketing performance across the key metrics.

YouTube was one of the strongest channels, particularly in terms of ROI and engagement.

The analysis also compared the performance of different companies and marketing channels to identify opportunities for future campaign optimization.

## Files

- Excel Dashboard – contains the interactive dashboard and analysis.
- Analysis PDF – contains the detailed findings and recommendations.
